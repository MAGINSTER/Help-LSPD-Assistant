# Bot-Assist

> **Мовы:** [🇷🇺 Русский](https://lspd-assistant.gitbook.io/lspd-assistant-docs/) · [🇺🇸 English](https://lspd-assistant.gitbook.io/lspd-assistant-docs/documentation-lspd-assistant-bot-en/) · [🇺🇦 Українська](https://lspd-assistant.gitbook.io/lspd-assistant-docs/documentation-lspd-assistant-bot-ua/) · **🇧🇾 Беларуская** (цяпер)

## Bot-Assist

### Bot-Assist

Bot-Assist прызначае ролі супрацоўнікам LSPD на Discord-серверы арганізацыі.

#### Прызначэнне

Бот спрашчае кіраванне доступам на серверы. Супрацоўнікі атрымліваюць ролі ў адпаведнасці са сваім статусам або аддзелам.

#### Што робіць бот

* Прызначае ролі ўдзельнікам Discord-сервера LSPD.
* Дапамагае падтрымліваць структуру роляў у актуальным стане.
* Памяншае аб'ём ручной працы для адміністратараў.

#### Каманды

**`/clear`**

Выдаляе паведамленні ў бягучым канале.

Пакажыце колькасць паведамленняў для выдалення — ад `1` да `500`.

{% hint style="warning" %}
Перад выкананнем каманды пераканайцеся, што выбраны правільны канал.
{% endhint %}

**`/settings`**

Адкрывае інтэрактыўную панэль налад сервера.

Выкарыстоўвайце панэль для налады Bot-Assist на вашым Discord-серверы.

**`/setup`**

Адкрывае акно першапачатковай налады Bot-Assist.

Выкарыстоўвайце яго для налады бота і роляў на Discord-серверы.

#### Для каго гэтая дакументацыя

Гэтая дакументацыя прызначана для адміністратараў Discord-сервера і супрацоўнікаў LSPD.
