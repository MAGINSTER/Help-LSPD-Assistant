# Інструкцыі

> **Мовы:** [🇷🇺 Русский](https://lspd-assistant.gitbook.io/lspd-assistant-docs/) · [🇺🇸 English](https://lspd-assistant.gitbook.io/lspd-assistant-docs/documentation-lspd-assistant-bot-en/) · [🇺🇦 Українська](https://lspd-assistant.gitbook.io/lspd-assistant-docs/documentation-lspd-assistant-bot-ua/) · **🇧🇾 Беларуская** (цяпер)

## Інструкцыі

### Запыт ролі

Bot-Assist дазваляе запытаць адну або некалькі роляў праз панэль **Кіраванне ролямі**.

{% stepper %}
{% step %}
#### Адкрыйце панэль роляў

Перайдзіце ў канал з паведамленнем Bot-Assist **Кіраванне ролямі**.
{% endstep %}

{% step %}
#### Выберыце ролі

Адкрыйце спіс і выберыце неабходныя ролі. Можна выбраць адну або некалькі роляў.
{% endstep %}

{% step %}
#### Адпраўце запыт

Пацвердзіце выбар. Мадэратары разгледзяць запыт і прызначаць ролі.
{% endstep %}
{% endstepper %}

### Як выглядае запыт

Пасля адпраўкі Bot-Assist публікуе запыт для мадэратараў. Ён утрымлівае:

* карыстальніка і яго нікнэйм;
* ролі, якія запытваецца прызначыць;
* даступныя дзеянні для мадэратара.

Мадэратар можа ўхваліць або адхіліць запыт. Таксама даступныя выдаленне паведамлення і запыт статыстыкі карыстальніка.

### Адхіленне запыту

Пры адхіленні запыту выберыце прычыну са спісу або пакажыце ўласную. Карыстальнік убачыць выбраную прычыну адхілення.

Даступныя наступныя прычыны:

* Немагчыма ідэнтыфікаваць сервер.
* Скрыншот абрэзаны.
* Гулец не з'яўляецца ўдзельнікам арганізацыі.
* Запыт адпраўлены для іншай фракцыі.
* Няправільны NickName.
* Няправільнае званне.
* Дата на скрыншоце састарэла.
* Уласная прычына.

Пасля адхілення Bot-Assist адпраўляе апавяшчэнне. У ім указваюцца мадэратар, карыстальнік, яго нікнэйм і прычына адхілення.

### Праверка статыстыкі

Націсніце кнопку **Статыстыка карыстальніка** ў запыце. Bot-Assist адправіць паведамленне аб запыце статыстыкі.

Паведамленне змяшчае карыстальніка, яго нікнэйм і мадэратара, які запытаў праверку. Гэта паведамленне бачаць толькі мадэратары.

#### Адказ карыстальніка

Пасля атрымання запыту адкрыйце статыстыку персанажа ў гульні і зрабіце скрыншот. Адпраўце яго ў адказ на запыт мадэратара.

На скрыншоце павінны быць бачныя нікнэйм персанажа і галоўнае акно статыстыкі.

### Выдаленне запыту з журналаў

Калі запыт выдаляецца, Bot-Assist стварае запіс у журнале. У ім указваюцца ID запыту і адміністратар, які выдаліў паведамленне.

Калі для запыту была запытана статыстыка, бот таксама запісвае ачыстку гэтага запыту.

### Скід лімітаў запытаў

Выкарыстоўвайце каманду `/reset_user`, каб скінуць ліміт запытаў для выбранага карыстальніка.

Bot-Assist пацвердзіць колькасць скінутых лімітаў. Пасля гэтага карыстальнік зможа адправіць новы запыт.

### Выдаленне ролі

Націсніце **Выдаліць ролю** ў панэлі кіравання ролямі. Затым выберыце ролю, якую трэба выдаліць.

{% hint style="info" %}
Ролі прызначаюцца пасля ўхвалення мадэратарам.
{% endhint %}
