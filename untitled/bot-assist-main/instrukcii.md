# Инструкции

## Инструкции

### Запрос роли

Bot-Assist позволяет запросить одну или несколько ролей через панель **Управление ролями**.

{% stepper %}
{% step %}
#### Откройте панель ролей

Перейдите в канал с сообщением Bot-Assist **Управление ролями**.
{% endstep %}

{% step %}
#### Выберите роли

Откройте список и выберите нужные роли. Можно выбрать одну или несколько ролей.
{% endstep %}

{% step %}
#### Отправьте заявку

Подтвердите выбор. Модераторы рассмотрят заявку и назначат роли.
{% endstep %}
{% endstepper %}

### Как выглядит заявка

После отправки Bot-Assist публикует заявку для модераторов. В ней указаны:

* пользователь и его никнейм;
* роли, запрошенные для выдачи;
* доступные действия для модератора.

Модератор может одобрить или отклонить заявку. Также доступны удаление сообщения и запрос статистики пользователя.

### Отклонение заявки

При отклонении заявки выберите причину из списка или укажите свою. Пользователь увидит выбранную причину отказа.

Доступны следующие причины:

* Не удаётся распознать сервер.
* Скриншот обрезан.
* Игрок не состоит в организации.
* Заявка подана на иную фракцию.
* Некорректный NickName.
* Некорректный ранг.
* Неактуальная дата скриншота.
* Своя причина.

После отклонения Bot-Assist отправляет уведомление. В нём указаны модератор, пользователь, его никнейм и причина отказа.

### Проверка статистики

Нажмите кнопку **Статистика пользователя** в заявке. Bot-Assist отправит сообщение о запросе статистики.

В сообщении указаны пользователь, его никнейм и модератор, который запросил проверку. Это сообщение видят только модераторы.

#### Ответ пользователя

После запроса откройте игровую статистику персонажа и сделайте скриншот. Отправьте его в ответ на запрос модератора.

На скриншоте должны быть видны никнейм персонажа и окно основной статистики.

### Удаление заявки в логах

При удалении заявки Bot-Assist создаёт запись в логах. В ней указаны идентификатор заявки и администратор, удаливший сообщение.

Если для заявки запрашивали статистику, бот также фиксирует очистку этого запроса.

### Сброс ограничений на заявки

Используйте команду `/reset_user`, чтобы сбросить ограничение на заявки выбранного пользователя.

Bot-Assist подтвердит количество сброшенных ограничений. После этого пользователь сможет отправить новую заявку.

### Снятие роли

Нажмите **Снять роль** в панели управления ролями. Затем выберите роль для удаления.

{% hint style="info" %}
Роли выдаются после одобрения модераторами.
{% endhint %}
