# Bot-Assist

## Bot-Assist

Bot-Assist выдаёт роли сотрудникам LSPD на Discord-сервере организации.

### Назначение

Бот упрощает управление доступом на сервере. Сотрудники получают роли, соответствующие их статусу или подразделению.

### Что делает бот

* Выдаёт роли участникам Discord-сервера LSPD.
* Помогает поддерживать актуальную структуру ролей.
* Снижает объём ручной работы администрации.

### Команды

#### `/clear`

Очищает сообщения в текущем канале.

Укажите количество сообщений для удаления — от `1` до `500`.

{% hint style="warning" %}
Перед запуском команды убедитесь, что очищаете нужный канал.
{% endhint %}

#### `/settings`

Открывает интерактивную панель настроек сервера.

Используйте панель для настройки работы Bot-Assist на вашем Discord-сервере.

#### `/setup`

Открывает окно первоначальной настройки Bot-Assist.

Используйте его для настройки бота и ролей на Discord-сервере.

### Для кого эта документация

Документация предназначена для администраторов Discord-сервера и сотрудников LSPD.
